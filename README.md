# 📜 Chronicle — Oracle Fleet Feed (frontend)

Live UI for the Chronicle activity feed. Single static `index.html`, no backend.
Fetches `oracle-chronicle.laris.workers.dev/api/feed` (real Discord events synced by every oracle), renders a color-coded live timeline with per-oracle filters.

Design via the **ui-ux-pro-max** skill (Fira Code/Fira Sans pairing, slate+green palette).
